Centralized Application Logging

Containers→Grafana Alloy→Loki→Grafana

What I worked on

  • Implemented centralized log collection using Grafana Alloy.
  • Configured Loki as the centralized log storage and query layer.
  • Integrated Grafana for log exploration and visualization.
  • Organized logs using application, container, environment, and service labels.
  • Created dashboards and queries for production troubleshooting.
  • Enabled developers to investigate logs without direct VPS or Docker access.
